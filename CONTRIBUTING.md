# Contributing

1. Open an issue to discuss material enhancements.
2. Fork, create a branch, and keep the application static and dependency-free.
3. Do not introduce tokens, private repository metadata, credential prompts, or third-party trackers.
4. Run `npm run check` and `npm test`.
5. Verify small screens, keyboard controls, API failures, and link safety for UI changes.
6. Open a pull request with the scope, tests, tradeoffs, and screenshots where relevant.

For vulnerabilities, use [SECURITY.md](SECURITY.md), not public GitHub issues.
