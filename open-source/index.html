GitHub Reminders

Productivity · GitHub Action

Schedule reminders directly inside GitHub issue and pull-request conversations. The published v1.0.1 workflow uses GitHub-native comments and scheduled Actions—without an external database or hosted reminder service. The maintenance release includes strengthened metadata checks, safer mention handling, and improved retry handling.

  • Use /remind commands in issues or PRs
  • Receive a GitHub mention when a reminder is due
  • Run with scoped GitHub Actions permissions

Scheduled delivery is best effort and can be delayed; exactly-once delivery is not guaranteed. The published maintenance release is v1.0.1.

Caivra Repo Gallery

Discovery · Static web application

Browse public GitHub organizations and user profiles in a clear, searchable gallery. Search, filter, sort and share project views directly in your browser.

  • Search repositories, topics and descriptions
  • Filter by language and sort loaded repositories
  • Share a gallery link without signing in

Only public repository metadata is displayed. Results are limited to loaded API pages and GitHub's anonymous API rate limits.
