## Tracking process

Review and record the same public counts approximately 7, 14, and 30 days after first promotion. Separately report:
- GitHub issue discussions and outside contributions (count evidence, distinguish author);
- real accepted installations/usage signals for GitHub Reminders if consent/coverage allows;
- Repo Gallery site analytics only if a privacy-reviewed measurement tool is explicitly installed;
- posts published and links to actual published post pages;
- any GitHub Marketplace listing *after* the release/eligibility gate.

**Not available from current public API:** GitHub traffic/unique visitors, individual install numbers, click-through rates, LinkedIn impressions, conversion rates or user identities. These require owner account views or explicitly connected analytics.
