# Security

This project consumes **only public GitHub API data** in the visitor's browser. It has no server, auth system, analytics, or private repository access.

Report security vulnerabilities through **Security → Advisories → Report a vulnerability** if enabled. If private reporting is unavailable, open a public issue requesting a private channel **without** reproduction details or sensitive data.

Only the current default-branch version is maintained. No formal security certification or response-time promise is implied.
